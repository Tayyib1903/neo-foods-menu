# NEO FOODS Menü

Statische Website für GitHub Pages. Keine Installation, Bibliothek oder externen Schriftarten nötig.

## Dateien veröffentlichen

Die Dateien und den Ordner `assets` aus dem ZIP in das Stammverzeichnis des bestehenden Repositorys übernehmen. Die gleichnamigen HTML-Dateien ersetzen. `assets` muss ein Ordner bleiben. Bestehende alte Dateien dürfen für bisherige Direktlinks erhalten bleiben.

GitHub Pages kann weiterhin aus demselben Branch und Stammverzeichnis bereitgestellt werden. Diese Lieferung wurde lokal vorbereitet und noch nicht auf GitHub veröffentlicht.

## Karten und Sprungziele

- `speisekarte.html`: Frühstück (1), Croissants (2), Salate (3), Desserts (4)
- `getraenkekarte.html`: Matcha (1), Coffee mit Tee (2), Refresher (3), Soft Drinks (4–5)
- `eiskarte.html`: Eissorten und Kugelpreis

Mit `#page=2` öffnet eine Karte direkt die zweite Seite. Auf dem Desktop ist sie Teil der entsprechenden Doppelseite.

Mobil: horizontal wischen. Desktop: ziehen, Pfeile oder Pfeiltasten benutzen. Vergrößern öffnet eine Ansicht mit Zoom. Die Textansicht stellt die ausgewählte Seite als auswählbaren Text bereit. PDF-Downloads sind unabhängig vom Blättermenü verfügbar. Der Browser-Zoom bleibt erlaubt.

## Datenpflege

PDFs: `speisekarte.pdf`, `getraenkekarte.pdf`, `eiskarte.pdf`.
Die abgeleiteten Seitenbilder liegen unter `assets/speisen-*.webp`, `assets/getraenke-*.webp` und `assets/eis-1.webp`.
Bei Menüänderungen PDF, Bild und zugehörigen `NEO_MENU.pages[].text`-Eintrag gemeinsam aktualisieren, damit alle Ansichten übereinstimmen.

Die Fotos stammen aus der V8-Karte. Preise, Zutaten und vorhandene Allergenangaben wurden übernommen. Rechtstexte wurden nicht inhaltlich verändert.
